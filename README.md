# Deep Compartment Model 재현 — 혈우병 A 수술기 8인자

> Janssen A, Bennis FC, Mathôt RAA.
> **Deep compartment models: A deep learning approach for the reliable prediction of time-series data in pharmacokinetic modeling.**
> *CPT: Pharmacometrics & Systems Pharmacology* 2022;11(7):934–945. [doi:10.1002/psp4.12808](https://doi.org/10.1002/psp4.12808)

논문의 시뮬레이션 실험을 밑바닥부터 다시 구현하고, 보고된 숫자와 대조하고,
재현한 모델을 실제로 쓸 수 있는 형태(웹 앱)까지 만든 개인 프로젝트입니다.

<details>
<summary><b>In English</b></summary>

An independent reproduction of the deep compartment model (neural network → PK
parameters → 2-compartment ODE) for perioperative factor VIII dosing in hemophilia A.
All 12 simulation conditions were re-implemented from scratch and compared against the
reported values: the paper's central claim — ζ₀ initialization outperforms the standard
DCM — reproduced in **12/12** conditions. Absolute accuracy was lower in all 12
(mean −18.1 %p); splitting the test set showed the gap comes **entirely from pediatric
patients** (adults 97.9 % vs. the paper's 99.4 %; children 64.4 %). The repository also
ships a Streamlit app that runs the reproduced model for dose design with MAP Bayesian
individualization. Tables and figures below are in Korean.

</details>

## 무엇을 하는 모델인가

기존 약동학(PK) 모델링은 사람이 **관계식의 모양을 직접 써 넣습니다.**

```
CL = 150 × (체중/68)^0.75 × (나이/40)^−0.17 × 1.26^O형 × 0.93^대수술
```

`^0.75`, `^−0.17`, `1.26` — 이 지수와 계수를 사람이 정하고 시작합니다.
Deep Compartment Model(DCM)은 **그 자리를 비웁니다.**

```
환자 정보 4개 ──▶ 신경망 ──▶ PK 파라미터 ζ (CL·V1·Q·V2) ──▶ 2구획 미분방정식 ──▶ 농도
                    ▲                                                          │
                    └──────────────── 오차 역전파 ─────────────────────────────┘
```

핵심은 **미분방정식을 통과해서 기울기가 흐른다**는 점입니다. 신경망은 농도만 보고
학습하지만, 내놓는 것은 임상적으로 읽히는 PK 파라미터입니다.

### 1. 12조건 격자 — 논문의 주장은 12/12 재현됨

채혈 횟수 4가지 × 학습 환자 수 3가지. 각 조건마다 **표준 DCM**과 **ζ₀ 초기화** 두 방식을 5회씩.

- **ζ₀ 초기화가 표준 DCM보다 높다** — 논문 12/12, 재현 12/12. 방향이 전부 일치했습니다.
- 절대값은 12조건 전부에서 우리가 낮았습니다 (평균 −18.1 %p). 이유는 아래 2·3절입니다.
- 우리 표준 DCM이 특히 낮은 것은 **정해진 학습 예산 안에서 수렴하지 못하기 때문**입니다.
  같은 조건을 20만 에포크까지 늘리면 68.4%까지 오릅니다 (`results/longstd.json`).
  ζ₀ 초기화는 2,000~2,700 에포크에서 제 성능을 냅니다 — 그것이 이 방법의 요점입니다.

> 정확도 = 예측이 참값의 ±0.05 IU/mL 안(0.15 미만은 ±0.02)에 든 비율.
> 논문과 동일한 기준이며, 학습 데이터에 σ=0.05 가우시안 잡음을 더한 것도 동일합니다.
>
> **조기 종료** — 학습셋의 20%를 검증으로 떼고 50 에포크마다 검증 손실을 확인,
> 20회 연속 나아지지 않으면 멈추고 가장 좋았던 가중치를 되살립니다 (최대 6,000 에포크).
> 논문의 *"Models were trained until MSE stopped improving"* 에 대응하는 구현입니다.
>
> 재현 : `python src/01_grid.py` → `results/grid.json` (약 8분)

### 2. 격차의 정체 — 성인에서는 재현되고, 소아에서 벌어짐

채혈 6회 · 120명 · ζ₀ 조건에서 시험 환자 380명을 성인과 소아로 나눠 채점했습니다 (5회 반복).

| | 전체 | 성인 | 소아 |
|---|---|---|---|
| 재현 | 86.7 ± 1.9 % | **97.9 ± 1.6 %** | **64.4 ± 5.5 %** |
| 논문 | 99.4 % | — | — |

**성인만 놓고 보면 논문과 1.5 %p 차이입니다.** 격차는 전부 소아에서 나옵니다.

소아는 체중이 5–85 kg로 성인(45–111 kg)보다 훨씬 넓게 흩어져 있는데,
학습 120명 중 소아는 평균 39명뿐입니다. 넓은 범위를 적은 데이터로 배워야 합니다.
반복 편차도 성인 ±1.6 %p인 데 비해 소아는 ±5.5 %p로 세 배 넘게 흔들립니다.

> 재현 : `python src/06_subgroup_adult_child.py` → `results/subgroup.json` (약 1분)

### 3. 출발점을 어디에 두는가 — ζ₀ 초기화의 정체

두 방식의 차이는 신경망 출력을 PK 파라미터로 바꾸는 **마지막 한 줄뿐**입니다.

```python
# ① 표준 DCM               학습 시작 때 출력≈0 → softplus(0)=0.69
zeta = F.softplus(out)     # → CL 0.6 · V1 0.7 · Q 0.8 · V2 0.7 에서 출발

# ② ζ₀ 초기화              학습 시작 때 출력≈0 → CELU(0)=0 → ζ = ζ₀
zeta = z0 * (F.celu(out, alpha=0.5) + 1)
# z0 = [150, 2500, 150, 2000]  ← 임상에서 알려진 성인 표준값
```

각자의 정점에서 신경망이 내놓은 값 (500명 중앙값):

| | ① 표준 (4만 에포크) | ② ζ₀ (1만 에포크) | 참값 |
|---|---|---|---|
| CL (mL/h) | 12.9 | 116 | 158 |
| V1 (mL) | **0.7** | 2,809 | 2,872 |
| Q (mL/h) | 1.2 | 136 | 163 |
| V2 (mL) | 16.8 | 2,107 | 1,953 |
| **투여 직후 예측 농도** | **2,935 IU/mL** | 0.80 | 0.83 |

**정확도는 ①이 더 높습니다(68.4 % vs 57.7 %). 그런데 ①의 V1은 0.7 mL — 몸에 있을 수 없는 값입니다.**

### 4. 그 정확도가 못 보는 것

정확도는 0.5–48시간의 49개 지점에서만 잽니다. 시점별로 쪼개면:

| 시각 | ① 표준 | ② ζ₀ | |
|---|---|---|---|
| 0.5 h | 84.2 % | 51.6 % | ● 채혈 |
| **1 h** | **2.1 %** | 57.6 % | 채혈 사이 |
| 4 h | 87.6 % | 60.0 % | ● 채혈 |
| 24 h | **100.0 %** | 61.8 % | ● 채혈 |
| 48 h | 26.1 % | 47.4 % | ● 채혈 |
| 범위 | 2.1 – 100.0 % | 47.4 – 63.2 % | |

**①의 봉우리는 정확히 채혈한 시점 위에 있습니다.** 빠른 상(α)을 반감기 2분짜리 스파이크로
압축해 첫 채혈(0.5 h) 이전에 숨겼기 때문에, 채혈과 채혈 사이에서 곡선이 급강하합니다.
채점하지 않는 투여 직후에서는 참값의 **3,540배**를 내놓습니다.

②는 47–63 % 사이에서 평평하고, 한 번도 본 적 없는 시점(0 h, 72 h)에서도 참값의 0.96–1.07배입니다.

**① 은 채혈한 여섯 점을 지나가는 곡선을 만들었고, ② 는 곡선의 모양을 맞혔습니다.**

### 5. 신경망이 실제로 배운 것

신경망에는 `^0.75`도 `1.26`도 알려 준 적이 없습니다. 그런데:

| | 참값 | 신경망 |
|---|---|---|
| O형 효과 | 1.26배 | **1.27배** |
| 대수술 효과 | 0.93배 | 0.97배 |
| 체중 곡선 | `(체중/68)^0.75` | 모양을 거의 그대로 되찾음 |

강한 효과(26 %)는 소수점까지 맞혔고, 약한 효과(7 %)는 절반쯤만 잡아냅니다.

재현한 모델을 그대로 쓰는 Streamlit 앱입니다.

```bash
cd app
pip install -r requirements.txt
streamlit run streamlit_app.py
```

**입력** 환자 4가지(체중·나이·혈액형 O·대수술) · 투여 계획 · (선택) 채혈로 잰 실측 농도
**출력** 시간별 예측 농도 곡선 · 세 구간 판정(미달/유지/초과) · 권장 로딩 용량과 투여 간격

- 신경망 4→64→16→4 (가중치 1,428개)를 `model.json` 에 담아 두었습니다. 시험 정확도 **93.7 %**.
- 실측 농도를 넣으면 **MAP 베이지안**으로 개인 보정합니다.
  사전분포는 Hazendonk 2016의 개체간 변이(ω_CL 0.37 · ω_V1 0.27), σ = 0.05.
- 2구획 해석해를 직접 구현했습니다. 반복 볼루스는 중첩, 지속 주입은 적분.
  정상상태에서 `C = R/CL`, `A/α + B/β = V1/CL` 로 검증했습니다.

> 시뮬레이션 데이터로 학습한 **재현 연구용 도구**입니다. 실제 진료 판단에 사용할 수 없습니다.

## 가상환자 500명은 어떻게 만들었나

논문은 *"covariate distributions fit to the original dataset"* 이라고만 적고 있어,
원 데이터(Hazendonk 2016)의 공개된 요약표에서 분포를 다시 세웠습니다.

| | 출처 | 우리 재현 |
|---|---|---|
| 성인 비율 | 71 % (198건 중 140건) | 67.0 % |
| 체중 중앙값 | 성인 75 kg · 소아 19 kg | 69.9 kg |
| 나이 중앙값 | 성인 40세 | 36.0 세 |
| 최고 농도 | 0.890 IU/mL | 0.801 |
| 투여량 | 25–50 IU/kg (250 배수 반올림) | 동일 |

참값을 만든 식 (Hazendonk 2016, Table 4·5):

```
CL = 150  × (체중/68)^0.75 × (나이/40)^−0.17 × 1.26^O형 × 0.93^대수술
V1 = 2810 × (체중/68) × (나이/40)^−0.09
Q  = 160  × (체중/68)^0.75
V2 = 1900 × (체중/68)
```

여기에 개체간 변이(ω_CL 0.37 · ω_V1 0.27)와 측정 오차(σ 0.05)를 얹었습니다.

## 한계

- **개체간 변이를 숫자로 내놓지 못합니다.** 기존 NLME는 "CL이 37 % 흩어진다"를 값으로
  보고하지만 DCM은 그 값을 만들지 않습니다. 논문 저자들도 Discussion에 한계로 적었습니다.
- **불확실성 구간이 없습니다.** 예측 농도 하나만 나오고 "얼마나 믿을 만한가"가 없습니다.
- **구조는 여전히 사람이 정합니다.** 2구획이냐 3구획이냐는 사람의 선택입니다.
- **재현 결과가 2–11 %p 흔들립니다.** 같은 설정으로 다시 돌려도 값이 움직입니다.
  논문이 5회 반복 평균을 쓴 이유를 직접 확인했습니다.
- **소아에는 아직 쓸 수 없습니다** (64 %). 위 2번 참조.
